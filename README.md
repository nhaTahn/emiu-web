# em iu.

Published static website: https://nhatahn.github.io/emiu-web/

Confirmed flower and gift choices, notes and names automatically save to the owner’s private Google Sheet. Updates reuse the browser’s row. A matching Google receipt is required before the page reports success. Photos, avatars, drinks and letters are excluded from Sheet payloads.

Visitors can also copy/share their recap. Photos added through the page stay on that device; the included album is served with the website.
